# Planificador de Gastos

Aplicación web para registrar y visualizar gastos personales. Permite categorizar ingresos y egresos para tener un mejor control financiero.

🔗 **[Ver demo en vivo](https://lighthearted-sunshine-dedd3f.netlify.app/)**

---

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

---

## Funcionalidades

- Registro de ingresos y gastos
- Categorización de movimientos
- Visualización del balance actual
- Interfaz responsive

---

## Instalación local

```bash
git clone https://github.com/laujml/practica4web2.git
cd practica4web2
```
Abrir `index.html` en el navegador.
